# Project Reflection Capsules

Feature 与 milestone 完成时，把实现和流程教训写成独立反思胶囊；Feature spec 只保留链接。

文件名：`YYYY-MM-DD-{topic}-capsule.md`。

```markdown
---
capsule_id: YYYY-MM-DD-{topic}
feature_ids: [F000]
context: "完成对象与边界"
---

# {Title}

## Context

## What Worked

## What Failed

## Trigger Missed

## Doc Links

## Rule Update Target
```

六个章节均需填写；没有内容时明确写“无”。
